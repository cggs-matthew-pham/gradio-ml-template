# Pattern Detectors — Machine Learning

Starter repository for the second half of the Pattern Detectors unit.

Use this repo for:

- Tutorials 6–10
- Pattern Detector starter templates
- text, image and audio classification pathways

Tutorials 1–5 use the original Python + Gradio repository.

## Getting started

1. Open this repo in a Codespace using **Code → Codespaces → Create codespace on main**.
2. Wait for setup to finish. The required Python packages are installed automatically.
3. Follow the tutorial on Schoolbox.
4. Create each tutorial file as instructed.
5. Commit your progress regularly. Your commit history is part of your evidence.

## Tutorial sequence

- Tutorial 6 — Pretrained text classification
- Tutorial 7 — Pretrained image classification
- Tutorial 8 — Train and use your own image classifier
- Tutorial 9 — Test and improve your classifier
- Tutorial 10 — Audio classification pathway
- Tutorial 11 — Choose and adapt a Pattern Detector starter

Tutorial 11 begins the project phase. You will choose a text, image or audio starter and adapt it for your own purpose.

## What this repo includes

This environment supports:

- Gradio interfaces
- Hugging Face text models with Transformers and PyTorch
- TensorFlow / Keras image models
- Teachable Machine image models
- audio input and analysis using Gradio, librosa and soundfile

Some pretrained models download extra files the first time they run, so the first run may take longer.

## Model files

For Tutorial 8 and some image starters, add your exported Teachable Machine files to the repository when instructed.

Do not rename model files unless the tutorial or starter specifically tells you to, because the Python code must match the filenames.

## File naming

Name tutorial files with their tutorial number and task, for example:

- `06_text_models.py`
- `07_image_classifier.py`
- `08_my_classifier.py`
- `09_test_improve.py`
- `10_audio_classifier.py`

Pattern Detector starters may use descriptive names such as:

- `starter_text_3class.py`
- `starter_image_classifier.py`
- `starter_audio_classifier.py`

Keep your own project files clearly named and commit meaningful milestones as you work.
