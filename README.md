# Gradio Template

Starter repo for Gradio + AI classification tasks.

## Getting started

1. Open this repo in a Codespace (green **Code** button → **Codespaces** → **Create codespace on main**).
2. Wait for setup to finish — this installs everything you need automatically. You don't need to create a virtual environment yourself.
3. Follow the tutorial doc (link on Schoolbox) to create and run your files as you go.

## File naming

Name each file with a zero-padded number and task, in order, for example:

- `01_rules_sentiment.py`
- `02_ml_sentiment.py`
- `03_8ball.py`

Numbers keep going up across the whole unit, not just one lesson. Zero-padding keeps files sorting correctly once you pass 9. Commit as you finish each one — your commit history is part of your evidence.
